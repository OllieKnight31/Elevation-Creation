## Section: Template Structure & Variable Categories

### Recurring Variable Types Across Hooks

1. **[desired outcome]** - The end result the audience wants (e.g., double sales, lose weight, 10x ROAS)
2. **[platform/business]** - Where or how the outcome happens (e.g., Instagram, email marketing, affiliate business)
3. **[number]** - Specific numerical quantity (e.g., 3, 50, 100)
4. **[business/niche/title]** - The profession or industry (e.g., photographer, entrepreneur, social media manager)
5. **[website/tool/app]** - Specific software or service being discussed
6. **[product or problem]** - The issue or solution being addressed
7. **[customer/niche]** - Direct address to target audience
8. **[time frame]** - Duration or timeline (e.g., 30 days, 90 days, overnight)
9. **[solution to problem]** - The fix or remedy being offered
10. **[problem]** - The pain point or challenge
11. **[wrong solution]** - Common misconception or failed approach
12. **[positive adjective]** - Desirable quality (e.g., perfect, best, ideal)
13. **[negative adjective]** - Undesirable quality (e.g., terrifying, volatile)
14. **[action/verb]** - What someone is doing (e.g., growing, building, scaling)
15. **[professional/authority]** - Expert or person with credentials
16. **[controversial descriptor]** - Unusual or contradictory identity
17. **[age]** - Age period or life stage
18. **[location, niche, business]** - Specific place, industry, or organization
19. **[ideal niche outcome]** - The best possible result for that audience
20. **[popular figure]** - Well-known person or influencer
21. **[ideal goal]** - Aspirational achievement
22. **[Relatable Current Struggle/limitation]** - Current pain or constraint the audience faces
23. **[high authority]** - Person, company, or institution with credibility
24. **[controversial in niche]** - Debated or unusual topic in that industry
25. **[dynamic]** - Trend or characteristic
26. **[item they're familiar with]** - Something the audience knows or uses regularly
27. **[device]** - Hardware or equipment (e.g., iPhone, laptop)
28. **[time period]** - Seasonal or temporal indicator (e.g., holiday season, summer)
29. **[related niche/business]** - Adjacent industry or field
30. **[authority qualifier]** - What makes someone an authority (e.g., top 1%, Fortune 500)
31. **[short time frame]** - Brief duration (e.g., 7 days, 2 weeks)
32. **[weird solution]** - Unconventional or surprising response
33. **[CTA]** - Call to action (e.g., start your business, apply now)
34. **[common held belief]** - Popular but potentially false assumption
35. **[similar comparison]** - Two comparable things
36. **[unique problem or talking point]** - Specific or unusual issue

## Section: Hook Application Patterns

### Pattern 1: Problem-Agitation-Solution (Multiple Hooks Use This)

Hooks 4, 12, 17, 32, 38-40, 44-45, 57, 60-64, 76-77, 81, 87, 91, 93-95 follow this pattern

**Structure**: Identify problem → Agitate the pain → Hint at solution

### Pattern 2: Authority-Proof (Multiple Hooks Use This)

Hooks 5, 15, 27-29, 35, 37, 40, 50, 68, 87 follow this pattern

**Structure**: Establish credibility → Share learned lesson → Show proof

### Pattern 3: Curiosity Gap (Multiple Hooks Use This)

Hooks 1, 2, 13, 16, 22, 28, 47-49, 52-53, 59, 62, 85 follow this pattern

**Structure**: Open loop → Ask question → Promise revelation

### Pattern 4: Contrarian/Forbidden Fruit (Multiple Hooks Use This)

Hooks 21, 38-39, 51, 89 follow this pattern

**Structure**: Challenge common belief → Reveal hidden truth → Offer alternative

### Pattern 5: Social Proof/Trend (Multiple Hooks Use This)

Hooks 19, 36, 46, 48, 54 follow this pattern

**Structure**: Reference authority or trend → Suggest following suit → Show benefit

### Pattern 6: Demonstration/How-To (Multiple Hooks Use This)

Hooks 11, 23-24, 29-30, 34, 42, 75, 77-78, 83 follow this pattern

**Structure**: Promise specific result → Show method → Deliver proof

### Pattern 7: Discovery/Personal Story (Multiple Hooks Use This)

Hooks 3, 14, 26, 33, 41, 55, 65, 70, 84, 86, 92, 97-98, 102 follow this pattern

**Structure**: Share experience → Reveal discovery → Offer insight

### Pattern 8: Qualification/Segmentation (Multiple Hooks Use This)

Hooks 19, 47, 70, 88 follow this pattern

**Structure**: Target specific audience → Exclude others → Create urgency for included group

### Pattern 9: Reverse/Opposite (Multiple Hooks Use This)

Hooks 20, 22, 45, 58 follow this pattern

**Structure**: State conventional wisdom → Flip it → Reveal counter-intuitive truth

### Pattern 10: Comparison (Multiple Hooks Use This)

Hooks 28, 44, 48, 65 follow this pattern

**Structure**: Compare two similar things → Show distinction → Highlight advantage
